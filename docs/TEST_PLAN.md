# 测试计划（标准十字键与直播切换）

## 测试设备
- Android TV Box，首轮目标设备 Android 14 / Amlogic S905X5M。
- 记录设备型号、RAM、Android 版本、WebView 版本、网络类型和屏幕分辨率。
- 标准十字方向键遥控器。

## 遥控器
- [ ] 上键切换到上一个频道。
- [ ] 下键切换到下一个频道。
- [ ] 频道列表关闭时左键打开列表。
- [ ] 频道列表打开时上下键移动焦点。
- [ ] 确定键播放焦点频道。
- [ ] 返回键关闭频道列表。
- [ ] 关闭列表后焦点和当前频道状态正确。
- [ ] 不依赖鼠标、飞鼠或触屏操作。

## 播放与换台
- [ ] 旧播放会话在换台时立即静音。
- [ ] 旧 Media3 播放器 stop/release。
- [ ] 旧 WebView 停止页面媒体并销毁。
- [ ] 切台后立即显示静态占位层。
- [ ] Media3 只有收到 onRenderedFirstFrame 才恢复声音并隐藏占位层。
- [ ] WebView 只有检测到页面 video 元素首帧才隐藏占位层。
- [ ] 页面加载完成但未检测到视频首帧时，继续显示等待状态。
- [ ] 快速连续换台 50 次，最终频道正确，无旧频道声音残留。
- [ ] 播放错误显示原因并可重试。
- [ ] 网络断开、恢复后应用不闪退。

## 官方来源
- [ ] 记录官网、直播页、首帧验证三个独立状态。
- [ ] CCTV-1 页面在目标盒子实测。
- [ ] CCTV-13 页面在目标盒子实测。
- [ ] 未经实测的北京、内蒙古、浙江、央视频资源不得标记可播放。

## 兼容与稳定性
- [ ] 720P / 1080P / 4K 输出布局无裁切。
- [ ] 连续播放 30 分钟无崩溃。
- [ ] 连续切台后内存与解码器资源无持续增长。
- [ ] 前后台切换后声音状态正确。
- [ ] APK 可安装、启动、卸载。

## 验收规则
GitHub Actions 构建通过仅代表代码通过编译。实机播放、首帧、声音隔离及遥控器验收必须由目标设备测试确认。
