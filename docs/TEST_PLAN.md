## 0.2.0 局域网网页管理测试
- [ ] APK 可安装、启动、卸载。
- [ ] 电视启动后可进入网页管理页，显示访问地址、配对码和二维码。
- [ ] 同一 Wi-Fi 下手机/电脑可打开管理地址。
- [ ] 二维码可打开网页并自动提交配对码。
- [ ] 错误配对码被拒绝；未配对请求不能访问管理 API。
- [ ] 可以新增、编辑、删除频道。
- [ ] 每个频道可独立新增、停用、删除多个来源。
- [ ] 重启应用后频道与来源仍保存在本机。
- [ ] 非 HTTP/HTTPS、无主机名或含 URL 账号密码的地址被拒绝。
- [ ] 新增来源默认待验证，不会被当作免费已验证来源播放。
- [ ] 退出应用后管理端口停止监听。
- [ ] 十字键、飞鼠及 16:9 布局无明显问题。
