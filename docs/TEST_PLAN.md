# 测试计划

## 设备
- 首轮目标：S905X5M，Android 14。
- 待补：设备 RAM、WebView 版本、网络类型/速率、固件型号。

## 0.1.0 基础验收
- [ ] APK 可安装、启动、卸载。
- [ ] 16:9 电视布局无裁切。
- [ ] 十字键可在所有可聚焦控件间移动。
- [ ] OK 可触发当前焦点控件。
- [ ] 飞鼠可点击控件。
- [ ] 返回键行为符合页面层级。
- [ ] 无已验证频道时显示明确空状态，不展示待验证频道。

## 播放验收（后续版本）
- [ ] Media3 官方授权媒体源播放。
- [ ] WebView 官方直播页播放。
- [ ] 切台后旧播放器停止。
- [ ] 不发生双重音频。
- [ ] 断网、超时、来源失效提示明确。
- [ ] 30 分钟连续播放。
- [ ] 同频道多个免费来源可手动切换及自动故障切换。
