## 2. 退出机制详细设计（本次新增，需你确认形态）

**触发范围**：仅在主界面（Home）按返回键触发。在播放页 / 频道抽屉 / EPG 等子界面按返回键，仍是逐层返回，不直接触发退出。

**交互流程**：

1. 主界面按「返回」→ 不切页，弹出提示层（文案拟为"再按一次返回键退出应用"）
2. 提示层显示期间：
   - 再按「返回」→ 真正退出 App
   - 按其他键 / 点击提示层以外区域 / 超时（建议 3 秒）→ 提示层消失，回到主界面
3. 提示层形态：✅ 已确认 = **居中对话框**（半透明遮罩 + 大字"再按一次返回键退出"，3 秒无操作自动消失）

**技术要点**：

- 用 Compose `BackHandler` 仅在 Home 屏启用，子屏由各自导航消费返回事件
- 提示层为原生 Composable 覆盖层，不依赖 WebView
- 二次返回需在时间窗内（建议 3 秒），超时重置
