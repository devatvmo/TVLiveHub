# TVLive 正式产品需求文档（PRD）

**文档版本：** 1.1  
**开发基线：** 0.3.0-alpha.1  
**平台：** Android TV Box  
**输入设备：** 标准十字方向键遥控器

## 1. 产品定位
TVLive 是面向安卓电视盒子的国内广电官方直播应用。产品首要目标是稳定播放和高质量换台体验。

## 2. 已确认范围
- 仅安卓电视盒子。
- 仅标准十字方向键遥控器。
- 仅国内广电官方直播页面或明确授权媒体资源。
- 仅互联网直播。
- 原生 Media3 为主要播放引擎，WebView 为官方网页兼容引擎。
- 不做飞鼠、鼠标指针、触屏、手机端或局域网网页管理。

## 3. 核心用户流程
启动应用 → 进入全屏直播 → 上下键换台 → 左键打开频道列表 → 上下移动焦点 → 确定播放 → 返回关闭列表。

## 4. P0 功能
### 4.1 全屏播放
- 横屏沉浸式界面。
- 默认隐藏复杂控制栏。
- 显示当前频道名称与播放状态。

### 4.2 标准遥控器
- 上/下：频道切换。
- 左：呼出频道列表；列表打开时左键关闭。
- 列表内上/下：移动焦点。
- 确定：播放选中频道。
- 返回：关闭列表。
- 不适配飞鼠或触屏。

### 4.3 切台体验
1. 接收换台指令。
2. 立即关闭旧频道声音。
3. 停止旧播放会话。
4. 显示静态占位层。
5. 释放旧播放器/WebView。
6. 初始化新频道。
7. 等待真实视频首帧。
8. 首帧确认后隐藏占位层并恢复新频道声音。

快速切台采用最新请求优先，过期加载任务不得覆盖最终选择。

### 4.4 播放器
- Media3 支持获准使用的 HLS / DASH。
- Media3 首帧前静音，首帧后恢复音量。
- WebView 仅打开官方允许嵌入的 HTTPS 页面。
- WebView 页面加载完成不等于视频首帧。
- 无法确认首帧时继续显示等待/错误状态。

### 4.5 异常处理
- 网络错误、HTTP 错误、SSL 错误有明确状态。
- 提供重试入口。
- 不因某个频道失效影响应用和其他频道操作。

## 5. 官方资源准入
仅接入官方域名和明确授权媒体资源。禁止绕过登录、会员、地区限制、DRM 或访问控制。未在目标电视盒子上实际验证的资源只能标记为待验证。

## 6. P1/P2 后续功能
- 地方广电频道扩展。
- 频道收藏和最近观看。
- EPG 节目单。
- 官方资源健康检查。
- 多官方来源的合法故障切换。
- 播放设置和诊断日志。

## 7. 非功能需求
- 无旧节目声音残留。
- 无快速换台竞态错台。
- 无持续播放器资源泄漏。
- 适配 720P / 1080P / 4K 输出。
- 低内存设备可正常运行。
- 频道列表焦点清晰可见。

## 8. 发布验收
必须完成真实电视盒子安装、标准遥控器、首帧、声音隔离、快速切台和长时间播放测试。用户确认前不得标记正式稳定版。
