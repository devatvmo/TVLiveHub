## 核验等级
1. 官网可访问：仅确认域名/官网可打开。
2. 直播页面可访问：具体频道直播页面可打开。
3. 首帧已验证：在目标电视盒子上确认视频画面和声音均正常。

只有第 3 级可以标记为“实机已验证”。登录、会员、地区限制或 DRM 保护内容不纳入绕过范围。
