# 产品需求（0.1.0 基线）

## 产品定位
Android TV 本机综合电视直播应用。默认只展示已验证免费且合法播放的频道。

## 已确认需求
- 目标设备：Android TV / S905X5M，首轮设备 Android 14。
- 播放：Media3 + WebView 混合方案。
- 每个频道支持多个信号来源。
- 保留咪咕视频，同时支持央视频、央视网、地方广电及其他免费来源。
- 支持自动选源、故障切换、手动选源（后续迭代）。
- 支持普通十字键遥控器和飞鼠遥控器。
- 仅本机播放；不提供局域网 HTTP 转发或 M3U/TXT 输出。
- 版本、变更、测试和 APK 均需留档；正式稳定版必须由用户确认。

## 免费准入
仅 FREE_VERIFIED 来源可进入默认频道列表。登录、会员、付费、地区限制、未验证及失效来源不得作为免费可播来源展示。免费资格可能按节目/赛事和时间变化，必须记录验证时间。

## 合规边界
仅使用平台明确允许的官方网页、官方应用入口或授权媒体接口。不得绕过登录、会员、地区限制或 DRM，不提取受保护流，不伪装请求以规避访问控制。

## 0.1.0 范围
- Android TV 工程骨架和首页。
- 频道/多来源数据模型。
- 免费来源过滤。
- Media3 / WebView 播放组件基础实现。
- 首版不内置未经验证的真实直播地址。
