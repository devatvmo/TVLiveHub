# 产品需求（TVLive 0.3.0-alpha.1）

## 产品定位
仅面向 Android TV 电视盒子的国内广电官方直播应用。

## 已确认约束
- 设备：仅 Android TV / Android TV Box。
- 遥控器：仅标准十字方向键遥控器；不适配飞鼠、鼠标指针或触屏交互。
- 资源：仅国内广电官方直播页面或明确授权的媒体资源。
- 网络：互联网。
- 核心优先级：直播播放、上下换台、左键频道列表、无旧节目声音残留、静态占位图和首帧切换。
- 不开发手机/电脑网页管理端，不提供局域网视频代理或直播流转发。

## P0 功能
1. 横屏全屏直播主界面。
2. 上/下键切换频道，循环顺序由频道列表决定。
3. 左键打开频道列表；列表内上下移动，确定键播放，返回键关闭。
4. 切台时停止并释放旧播放会话，显示静态占位层。
5. Media3 播放器首帧前静音，首帧回调后才恢复音量。
6. WebView 仅加载允许嵌入的官方 HTTPS 页面；页面视频首帧可探测时才隐藏占位层。
7. 快速切台时取消/丢弃过期加载任务，最终目标频道优先。
8. 网络或页面错误时显示明确提示和重试入口。

## 官方资源准入
- 仅使用广电机构官方域名、官方应用公开入口或明确授权媒体接口。
- 不绕过登录、会员、地区限制、DRM 或访问控制。
- 不提取受保护媒体流。
- 区分官网可访问、直播页面可访问、实际视频首帧已验证三个状态。
- 未经目标盒子实际播放验证的频道必须标记为待验证。

## 非目标
- 飞鼠和鼠标指针。
- 手机端适配。
- 局域网网页管理。
- 用户自定义第三方直播源。
- 会员、登录、DRM 或地区限制规避。
- 首期 EPG、收藏、推荐和账号系统。

## 验收原则
开发版只用于测试；真实播放能力必须在目标电视盒子上验证。正式稳定版必须由用户确认。
