# 标准十字方向键遥控器规范

## 支持范围
只支持电视盒子常见标准十字方向键遥控器，不承诺飞鼠、鼠标、触屏或游戏手柄映射。

## 按键表
| 按键 | 直播界面 | 频道列表 |
|---|---|---|
| 上 | 上一个频道 | 焦点上移 |
| 下 | 下一个频道 | 焦点下移 |
| 左 | 打开频道列表 | 关闭频道列表 |
| 右 | 保留给系统/后续信息面板 | 不定义额外动作 |
| 确定 | 显示频道信息 | 播放当前焦点频道 |
| 返回 | 系统返回行为 | 关闭频道列表 |

## 焦点规则
- 频道列表打开时，焦点默认落在当前频道。
- 焦点项必须有明显高对比度边框或背景。
- 上下键只移动焦点，不自动播放。
- 确定键才切换到焦点频道。
- 关闭频道列表后回到直播界面。
- 切台过程不应丢失方向键响应。

## 验收
使用真实标准遥控器逐项测试，模拟器键盘测试不能代替实机验收。
